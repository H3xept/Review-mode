## [1.0.0] - 2026-08-15

### Added

- Dependency-free review interface for HTML pages.
- Whole-block and exact-text comments with durable anchors.
- Question, Issue, Nit, Idea, and Praise comment kinds.
- Agent-ready prompt and raw JSON exports.
- Chrome Manifest V3 extension shell.
- Idempotent command-line HTML installer.
- Optional Claude Code `PostToolUse` hook.
- Installable `review-mode` agent skill.
