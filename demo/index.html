A page to practise on

Every kind of block below is annotatable. Hit the Review pill bottom-right, click a paragraph, a table cell, a list item or the diagram — or select a phrase and use the ✎ bubble.

01 Paragraphs and phrases

Clicking anywhere in this paragraph attaches a comment to the whole block. Selecting just these seven words attaches it to the phrase instead, and the highlight comes back on reload.

Try a phrase. A phrase-level comment carries both the quote and the surrounding block into the generated prompt, so an agent can find the text even if the paragraph has been edited since.

02 Tables

Cells are separate anchors, so a comment lands on the row and column you meant.

Anchor kindHow it is storedSurvives an edit?
Whole block Structural path plus a hash of the block's text yes — falls back to a hash match anywhere on the page
Text selection The same, plus character offsets into the block yes — then a search for the quoted text
Deleted anchor Nothing left to match flagged — shown as detached in the sidebar and the prompt

03 Cards and lists

Comment kinds

  • Question — answer it and fold the answer in.
  • Issue — the claim is wrong; verify and correct.
  • Nit — wording or formatting.
  • Idea — evaluate, then apply or reject.
  • Praise — leave that part alone.

Keys

  • Alt+R toggles review mode.
  • ⌘↵ saves the open comment.
  • Esc closes the composer, then the sidebar.
  • Click a coloured pin to reopen a comment.
