# Code of Conduct

## Our pledge

We pledge to make participation in this project respectful and harassment-free for everyone.

## Expected behavior

- Be respectful and constructive.
- Discuss ideas and evidence, not personal attributes.
- Accept feedback with care.
- Keep issues and pull requests focused on the project.
- Respect privacy and security disclosure boundaries.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing, and sustained disruption are unacceptable.

## Enforcement

Project maintainers may edit, hide, or remove content that violates this policy. Maintainers may temporarily or permanently restrict participation.

Report conduct problems privately through a [GitHub security advisory](https://github.com/H3xept/review_mode/security/advisories/new). Include relevant links and context. Maintainers will protect the reporter's privacy where practical.

## Scope

This policy applies in project spaces and when someone represents the project in public spaces.
